# 빙고 게임 기획서

ABC 광장 퀴즈와 같은 서버에서 도는 별도 게임이다. 방·세션·관리자 인증이 퀴즈와 분리돼 있다(Socket.IO 네임스페이스 `/bingo`). 관리자 PIN은 퀴즈와 같은 `ADMIN_PIN`을 쓴다.

## 1. 입장

| 주소 | 대상 |
| --- | --- |
| `/bingo` | 플레이어. 퀴즈 입장 화면 오른쪽 위 「🎱 빙고」 버튼으로도 들어온다 |
| `/bingo/admin` | 관리자(PIN). 여러 화면을 동시에 열 수 있다 |

- 플레이어는 퀴즈와 같은 방식으로 캐릭터 15종 중 하나와 닉네임(1~8자, 중복 불가)을 정해 입장한다. 최대 15명.
- 새로고침·재접속하면 세션으로 복귀한다. 게임 진행 중(PLAYING·FINISHED)에는 새로 입장할 수 없다.

## 2. 진행 단계

| 단계 | 내용 | 다음 단계로 |
| --- | --- | --- |
| LOBBY | 입장 대기 | 관리자가 주제를 낸다 |
| FILLING | 플레이어가 5×5 판 25칸에 주제에 맞는 답을 쓰고 「제출하기」. 시작 전까지 「수정하기」 가능, 작성 중인 칸은 새로고침해도 유지(기기 저장). 관리자는 주제를 고칠 수 있다 | 접속 중인 플레이어가 모두 제출하고 제출자가 2명 이상이면 관리자가 「게임 시작」 |
| PLAYING | 부르는 순서(제출한 사람을 무작위로 섞음)대로 한 명씩 지워지지 않은 자기 칸을 골라 「부르기」 | 누군가 3줄 완성 |
| FINISHED | 우승자 발표 | 관리자 「새 판」 |

- 판 규칙: 25칸 모두 채워야 하고, 한 칸 20자까지, 한 판 안에 같은 답(아래 비교 규칙 기준)을 두 번 쓸 수 없다.
- 부르면 같은 답을 쓴 **모든 플레이어**(부른 사람 포함)의 칸이 자동으로 지워진다.
- 차례가 온 사람이 접속이 끊겨 있으면 건너뛴다. 차례 중에 멈춘 사람은 관리자가 「순서 넘기기」로 넘긴다.
- 매번 부른 뒤 3줄(가로·세로·대각선 12줄 중) 이상인 사람이 있으면 즉시 끝난다. 같은 순간 완성한 사람은 모두 우승.
- 「새 판」은 플레이어를 남기고 주제·판·기술을 초기화한다. 「모두 내보내기」는 플레이어를 모두 입장 화면으로 돌려보낸다(두 번 눌러 확인).

## 3. 답 비교 규칙

모든 공백(띄어쓰기·탭·전각 공백)을 지우고 영문 대소문자를 무시해 비교한다. `'안녕'`, `' 안녕'`, `'안 녕'`, `'     안       녕      '`는 모두 같은 답이다. 구현: `shared/bingo.ts`의 `bingoKey`.

## 4. 기술 (한 판에 각 1번)

| 기술 | 사용 가능 | 효과 |
| --- | --- | --- |
| 👀 훔쳐보기 | 게임 중 | 다른 플레이어와 칸을 골라 그 칸의 답(이미 지워졌는지 포함)을 본다. 대상 화면에 「'xx'가 플레이어님을 훔쳐보는 중입니다」 알림 |
| 😜 약올리기 | 칸 채우기·게임 중 | 대상 화면에 큰 메롱 애니메이션(약 3초)과 「xx님이 약올려요!」 |

한 번 쓰면 서버가 다시 쓰지 못하게 막고, 버튼은 「사용함」으로 바뀐다. 「새 판」에서 다시 채워진다.

## 5. 공개 범위

- 모두에게: 주제, 플레이어 목록, 제출 여부, 각자 완성한 줄 수, 부르는 순서·현재 차례, 부른 단어 기록, 우승자.
- 본인에게만: 내 판과 지운 칸, 훔쳐보기 결과.
- 관리자에게만: 모든 플레이어의 판과 지운 칸.

## 6. 이벤트 (`/bingo` 네임스페이스, `shared/bingo.ts`)

| 방향 | 이벤트 | 설명 |
| --- | --- | --- |
| C→S | `bingo:join`, `bingo:resume` | 입장·복귀 |
| C→S | `bingo:submit` `{ cells }`, `bingo:unsubmit` | 판 제출·수정 |
| C→S | `bingo:call` `{ index }` | 내 차례에 칸 부르기 |
| C→S | `bingo:peek` `{ targetId, index }` | 훔쳐보기(결과는 ack로 본인에게만) |
| C→S | `bingo:taunt` `{ targetId }` | 약올리기 |
| C→S | `bingo:admin:auth`, `bingo:admin:topic`, `bingo:admin:start`, `bingo:admin:skip`, `bingo:admin:newRound`, `bingo:admin:kickAll` | 관리자 |
| S→C | `bingo:snapshot` | 사람마다 다른 상태(내 판 포함) |
| S→C | `bingo:admin:boards` | 관리자에게 전체 판 |
| S→C | `bingo:called` | 누가 무엇을 불렀는지, 누구 칸이 지워졌는지 |
| S→C | `bingo:peeked`, `bingo:taunted` | 기술 대상에게 알림 |
| S→C | `bingo:kicked` | 모두 내보내기 |
